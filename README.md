# Оно тебе надо

Учебный проект Яндекс Практикума: страница аукциона вещей, в которые никто не верил.

Страница сверстана на HTML и CSS по макету. Используются семантическая разметка, Flexbox, Grid и локальные шрифты Raleway. Для просмотра откройте `index.html` в браузере.

Репозиторий: https://github.com/globalarray/ono-tebe-nado-ad
